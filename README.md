AI vs Human

A C-based collection of mini-games where players compete against computer-controlled opponents.

Features

- Multiple mini-games
- AI opponents
- Three difficulty levels
- Player statistics
- Score tracking
- Win/loss tracking
- Streak system
- Player name customization
- Data saving

Games

- Number Guessing
- Rock Paper Scissors
- Tic Tac Toe
- Memory Challenge
- Number Master
- Word Battle
- Survival Challenge

Technologies

- C Programming
- Standard C Libraries
- File Handling
- Random Number Generation

How to Run

Compile the program using GCC:

```bash
gcc main.c -o ai-vs-human
